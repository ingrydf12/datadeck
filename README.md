# DataDeck

Jogo de tendência educativa voltada para ensino de Estruturas de Cartas por meio de jogo de cartas lúdico para cadeira de Estrutura de Dados em Sistemas e Mídias Digitais (SMD), direcionada a alunos ingressantes ou pouca experiência com programação na área de tecnologia.
